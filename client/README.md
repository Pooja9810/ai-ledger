# Ledgerly: web app

The React + Vite front end of Ledgerly. See the **[main README](../README.md)** for what
the project is, how to run it, and the [design doc](../docs/design/ai-features.md).

```bash
npm install
npm run dev     # http://localhost:5173 (proxies /api to the server on :3001)
npm test        # Vitest
npm run lint    # oxlint
```
